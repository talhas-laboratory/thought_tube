Thoughtboard Showcase

A live rendering of your pluggable visual feed and moodboard

💡 How to view live data:

  1. Run the miniapp server in your terminal: python3 tools/run_thoughtboard_miniapp.py --port 8000
  2. Open this file (product/thoughtboard_v1/showcase.html) directly in your browser.
  3. Use the API to add chatbot conversations or visual cards, and refresh the page to see them update in real-time.
