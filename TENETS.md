# TENETS

These tenets are operational rules for this repo, not optional advice.

1. Preserve raw truth.
   Raw conversation artifacts are append-only and never rewritten in place.

2. Derived never overwrites source.
   Analyses, summaries, cards, and context packs are additive and must point back to source refs.

3. Evidence before elegance.
   Every surfaced conclusion must show why it exists and what source supports it.

4. Context is task-scoped.
   Agents receive the smallest useful context pack, not the whole archive by default.

5. Quiet by default.
   The system earns the right to interrupt. Default delivery is conservative and batched.

6. Core stays small.
   Domain specialization belongs in plugin overlays, not in the capture pipeline.

7. Reversible by default.
   Synthetic structures must export back to transparent markdown and JSON.

8. Agent work must be inspectable.
   Important work leaves manifests, artifacts, and decisions, not only prose.

9. Decisions become artifacts.
   Important product and environment decisions are logged as durable objects.

10. Same protocol everywhere.
    Live sessions, imports, reviews, and product work all use the same capture, analyze, materialize, and route pipeline.
