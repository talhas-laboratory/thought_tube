# Building Diary

This folder is the durable continuity surface for ongoing build sessions.

It exists to keep:

- session-by-session diary entries
- the active taskboard/backlog
- fully-spec'd design documents for new work

in one place so decisions, next steps, and implementation context do not get lost across sessions.

## Structure

- [Inner World Building Taskboard](./INNER_WORLD_BUILDING_TASKBOARD.md)
  The active backlog and sequencing surface.
- [2026-04-22 Building Session Diary](./2026-04-22-building-session-diary.md)
  The first diary entry in this folder, capturing the setup and current priorities.
- [2026-04-22 Library Governance Manager Design](./2026-04-22-library-governance-manager-design.md)
  Full design for semantic library management, curation, and selective rederivation.
- [2026-04-22 Deep Pruning And Semantic Curation Design](./2026-04-22-deep-pruning-and-semantic-curation-design.md)
  Full design for pruning sources, chunks, semantic residue, and derived artifacts safely.

## Working Rules

- Add one diary file per meaningful build session using `YYYY-MM-DD-<topic>.md`.
- Update the taskboard after each session if priorities, status, or dependencies changed.
- Put new design/spec documents here when they are active build inputs.
- Keep raw source material elsewhere. This folder is for planning, governance, and continuity.
