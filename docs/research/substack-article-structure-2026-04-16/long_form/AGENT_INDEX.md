# Long-Form Agent Index

## Overview

This is the modular default for expanded long-form content in this project.

- style posture: `structured explainer with optional narrative opening`
- audience posture: `deep thinkers who want clarity without flattening`
- modularity: `high`
- user adjustability: `high`

## Recommended defaults

- Keep modules `01`, `03`, `05`, `06`, `07`, and `10` enabled by default.
- Use `02` when a narrative or sensory opening improves flow.
- Use `04` when the topic contains multiple moving parts that need explicit mapping.
- Use `08` when the article should resolve toward decisions, defaults, or implications.
- Use `09` when uncertainty is part of the value rather than a weakness.
