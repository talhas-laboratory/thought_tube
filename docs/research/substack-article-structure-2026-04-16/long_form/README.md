# Modular Long-Form System

This folder translates the Substack research into a project-aligned long-form format for expanded content.

## Design goal

Create a long-form structure that is:

- easy to read
- easy to flow through
- modular
- individually adjustable by the user
- abstract enough to work across research, art, entrepreneurship, and other deep-thinker content
- aligned with the project's substrate-first architecture

## Default posture

The default is:

- `structured explainer`

with:

- an optional narrative opening
- explicit tension and stakes
- clear evidence handling
- a reusable pattern layer
- bounded uncertainty

This means the article should feel readable and human, but still inspectable.

## Best-fit substrate algorithms

These are the algorithms selected from the substrate library as the best fit for long-form expansion:

1. `signal-frame-extractor`
2. `object-model-projection`
3. `transformation-path-extractor`
4. `decision-commitment-extractor`
5. `guardrail-antigoal-extractor`
6. `tension-map-extractor`
7. `evidence-confidence-scaffold`
8. `open-question-missingness-extractor`
9. `reasoning-primitive-detector`

Conditional use:

- `contradiction-pair-extractor`

Only use contradiction as a default module when the source genuinely contains a hard clash, not just a soft tradeoff.

## Default module stack

1. Promise Frame
2. Entry Vector
3. Thesis and Reader Map
4. Object Field
5. Tension and Stakes
6. Evidence Ladder
7. Pattern and Transfer
8. Decisions and Implications
9. Open Questions and Boundaries
10. Close and Next Move

Each module can be:

- enabled or disabled
- reordered
- compressed or expanded
- made more narrative or more analytical
- made more explicit or more suggestive

## Rule

This system is a format substrate, not a rigid template.

It should help the writer preserve:

- clarity
- pressure
- evidence
- transferability

without forcing every article into the same voice.
