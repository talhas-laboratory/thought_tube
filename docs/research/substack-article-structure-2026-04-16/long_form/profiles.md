# Long-Form Profiles

## Purpose

These profiles let the same module stack adapt to different user preferences without changing the underlying format substrate.

## 1. Explainer Default

Use when:

- clarity is the priority
- the topic is concept-heavy
- the reader needs structured progression

Defaults:

- module `02` lighter
- module `04` medium
- module `06` heavy
- module `09` medium

## 2. Narrative-Leaning

Use when:

- the article needs emotional pull
- the writer wants an anecdotal opening
- the topic benefits from slow reveal

Defaults:

- module `02` heavy
- module `04` lighter
- module `05` medium
- module `06` medium
- module `10` more reflective

## 3. Research-Heavy

Use when:

- evidence density matters most
- the article compares models, studies, or frameworks
- credibility depends on explicit scaffolding

Defaults:

- module `04` medium
- module `06` heavy
- module `08` medium
- module `09` heavy

## 4. Pattern-Transfer

Use when:

- the article should produce reusable substrate
- the topic matters mainly because of the pattern it reveals

Defaults:

- module `05` medium
- module `07` heavy
- module `08` medium
- module `09` medium

## Adjustment rule

Profile changes should alter:

- emphasis
- density
- narrative level
- explicitness

They should not break the modular contract.
