## Product

Inner World v1 is a private cognitive layer that turns saved research, notes,
and conversations into ranked, evidence-backed insights that the user would
likely not have seen on their own.

## v1 defaults

- local-first
- manually seeded
- conservative trust mode
- Morning Batch as primary delivery
- archive/feed as secondary surface
- evidence-backed insights only
- domain specialization via plugins

## v1 user

Hybrid knowledge workers doing creative work across research, art,
entrepreneurship, and adjacent domains.

## v1 core loop

1. Seed conversations, notes, and imports.
2. Analyze them into concepts, connections, and reasoning primitives.
3. Rank insight candidates by relevance, evidence, and surprise.
4. Surface a small daily batch.
5. Learn from explicit feedback.

## Not v1

- social or shared inner worlds
- always-on real-time interruption
- autonomous external research as a default
- graph-first primary UI
- multimodal synesthesia as a core promise
