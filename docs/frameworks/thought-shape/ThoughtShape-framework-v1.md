# ThoughtShape Framework for Thought Tube

**Version:** 1.0 (chat-developed)  
**Date:** 2026-07-08  
**Status:** Design specification — integrated into unified framework synthesis

---

## 1. Executive Summary

Thought is not an isolated sentence. It is a **dynamic, multidimensional meaning-shape**.

Evolution:

```text
Maqām → Ḥāl → Tajallī
Station → State → Event / Disclosure
```

Operational expansion:

```text
Field → Entity → Dimension → Station → Facet/Subsystem → StateClaim
     → Relation → Event → Expression → Update
```

**Core formula:**

```text
Station × Dimension × Facet = StateClaim
Thought-shape = relations between StateClaims across dimensions
```

For Thought Tube, lenses (Founder, Product, Risk, Financial, Story, Visual, Brand) are **structured access modes** into the same underlying ThoughtShape — not independent prompts.

---

## 2. Core Thesis

A thought is a **relational configuration of meaning**.

Example — surface vs depth:

> "People know the logo, but they do not understand the brand."

ThoughtShape stores:

- Entity: Brand
- Station: Recognition (faceted)
- Logo recognition: high; Meaning recognition: low; Category recognition: confused
- Tension: surface familiarity vs semantic confusion
- Cross-dimensional effects on strategy, communication, conversion, founder psychology

---

## 3. Field

Pre-structured zone: vague feeling, intuition, half-sentence, bodily sense, mood, image, tension.

**Hold** — do not force premature structure. Meaningful but not yet clear is valid.

---

## 4. Entity, Dimension, Station

- **Entity** — brand, founder, product, self, idea
- **Dimension** — psychological, social, business, brand, financial, narrative, technical, aesthetic, spiritual…
- **Station** — possibility-space where meaning varies (recognition, safety, clarity, trust…)

**Station × Dimension → Projection** — same station projects differently per dimension.

---

## 5. Facet and Subsystem

Within one dimension, one station splits into facets.

Brand × Recognition:

- logo recognition, meaning recognition, category recognition, value recognition, emotional recognition, trust recognition…

**Facet** = aspect of station. **Subsystem** = facet with enough internal structure to expand (progressive resolution only when needed).

---

## 6. StateClaim

Qualified claim with: state, weight, salience, valence, confidence, evidence, provenance.

Multiple StateClaims coexist for different facets of the same station.

---

## 7. Relation, Event, Tension

- **Relation** — directional influence; cross-dimensional relations create the deepest shape
- **Event (Tajallī)** — disclosure, transformation, state-change
- **Tension** — unresolved pressure (e.g. familiarity vs comprehension)

---

## 8. Final Ontology

```text
ThoughtShape = Field + Entity + Dimension + Frame + Station + Facet/Subsystem
             + StateClaim + Relation + Event + Expression + Provenance + Confidence
             + Tension + Valence + Salience + TemporalContour + Telos + Modality
```

---

## 11. Progressive Depth (levels 1–6)

1. Raw field — "something feels off"
2. Basic shape — Entity → Station → unstable
3. Dimensional — dimension + station
4. Faceted — multiple StateClaims per station
5. Subsystem — expanded facet internals
6. Cross-dimensional — relations across dimensions

---

## 12. Design Principles

1. Thought is not a sentence
2. Thought is not flat
3. Stations project across dimensions
4. Stations split into facets
5. Facets become subsystems progressively
6. Relations create shape
7. Cross-dimensional relations are essential
8. Provenance is mandatory
9. Lenses are access modes, not prompts
10. Progressive resolution — Hold before Differentiate

---

## 13. One-sentence definition

> Thought Tube maps thoughts as living, multidimensional meaning-shapes: entities across dimensions, stations and facets with changing states, connected by relations, transformed by events, expressed through surfaces, grounded by provenance.
