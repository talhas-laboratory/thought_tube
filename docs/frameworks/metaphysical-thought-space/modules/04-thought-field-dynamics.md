# Module 04 — Thought Field Dynamics

## Purpose

Model thought-space as a **dynamic temporal field**, not a static map.

## Core formulation

> A thought-space is not a static map. It is a dynamic field where idea-entities become populated over time, with changing intensity, relation, and relevance.

> AI can turn nonlinear thought into a navigable **temporal-semantic space**, where ideas are gradually populated, intensified, connected, and actualized into artifacts.

The system maps **thought formation** — the becoming of an idea, not only the final idea.

## Six-phase formation cycle

| Phase | Description |
|-------|-------------|
| 1. Initial spark | Vague center: mood, phrase, symbol, question, image, tension, intuition |
| 2. Partial population | Some associations light up; others empty, weak, hidden, implied |
| 3. Nonlinear activation | Distant association suddenly becomes central |
| 4. Intensity shifts | Entities strengthen/fade; main idea may migrate |
| 5. Structural binding | System discovers what belongs together: references, metaphors, constraints, tones, goals, forms, contradictions |
| 6. Artifact formation | Enough structure populated → concrete artifact possible |

## Why temporal order matters

- Weak-at-first entity may become hidden key
- Side association may become main axis
- Vague emotional charge may later explain entire concept

**Requirement:** Preserve temporal unfolding of thought, not only final state.

## Per-entity dynamic properties

| Property | Meaning |
|----------|---------|
| activation_intensity | How strongly present |
| time_of_emergence | When it appeared |
| source | Where it came from |
| relation_strength | What it connects to |
| state | vague \| forming \| stable \| contradicted \| unresolved \| ready_for_output |
| directionality | Where it pulls the thought |
| artifact_potential | What it could become |

## Field-level invariant

Entities are **partially activated structures** inside a semantic field — not born as clean, complete objects.
