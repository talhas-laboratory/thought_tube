# Module 05 — Entity Composition

## Purpose

Define idea-entities as nested, recursive, temporally activated composite systems.

## Core formulation

> Every idea-entity is a nested system: made of smaller semantic, sensory, emotional, symbolic, and functional parts whose internal relations determine what the entity currently means.

> Each entity is a living cluster of sub-entities; interactions between sub-entities generate the entity's actual meaning.

## Structure (not linear)

```text
thought-field → entities → sub-entities → relations → intensities → emergent_meaning → artifact
```

Not: `thought → entity → output`

## Sub-entity type taxonomy

| Type | Examples (loneliness) |
|------|---------------------|
| sensory | empty room, silence, distance, cold light, slow movement |
| emotional | sadness, fear, longing, numbness, resentment, peace |
| memory | past moments, people, places, repeated experiences |
| symbolic | desert, island, window, abandoned house, night, fog |
| conceptual | separation, absence, invisibility, non-recognition, disconnection |
| behavioral | withdrawal, scrolling, overthinking, seeking/avoiding contact |
| aesthetic | muted colors, wide frames, reverb, minimal composition, slow pacing |

## Entity as temporary coalition

Same label, different coalitions → different meaning:

| Dominant sub-entities | Emergent reading |
|-----------------------|------------------|
| silence + space + self-containment | peaceful solitude |
| absence + non-recognition + exclusion memory | social rejection |
| vastness + smallness + existential scale | cosmic isolation |
| absence + beloved + memory + hope | romantic longing |
| silence + empty house + unseen presence | horror unease |

## Recursion

Sub-entities contain sub-entities (e.g. abandoned house → hidden room → secret, repression, threshold).

## Storage principle

Store **internal composition**, not only top-level label:

```text
loneliness = vast_empty_space + distant_human_presence + silence + longing
           + slow_time + blue_grey_palette + unresolved_need_for_recognition
```

## Entity vs shape (identity layer)

### Stable identity

One entity, one carrier (e.g. "home", "loneliness", "mother").

### Multiple shape-states

Same entity, different quality-configurations:

| Shape | Qualities |
|-------|-----------|
| home-as-safety | warm, enclosed, familiar, protective, soft |
| home-as-prison | locked, inherited, suffocating, watched, repetitive |
| home-as-loss | empty, unreachable, nostalgic, decayed, silent |
| home-as-origin | ancestral, formative, grounding, early, identity-shaping |

### Co-active shapes

Multiple shapes simultaneous (e.g. home-as-safety AND home-as-prison — tension is meaningful).

### Stored vs live shapes

- **Stored:** recurring, stable, worth saving
- **Live:** temporary session activations

Track: `stored_entity_profiles + current_activation_state`

## Entity formal structure

```text
Entity =
  stable_identity
  + quality_field
  + relation_graph
  + possible_shape_states
  + current_activation_state
  + temporal_history
```

## Shape promotion rule

> Temporary shape first. Stable recurring shape can be promoted into its own entity.

Example: `home-as-loss` (activation) → `lost home` (entity) → sub-shapes (grief, myth, exile, motivation, sacred origin).

## Anti-patterns

| Bad extreme | Problem |
|-------------|---------|
| One fixed entity | Too rigid; misses contradiction, ambiguity, complexity |
| Infinite duplicate entities | Fragments unity (home_1, home_2, nostalgic_home, ...) |

**Solution:** one entity, multiple shape-states.

## Entity master formula

```text
entity = identity + qualities + relations + intensity + temporal_state + potential_actualizations
```

## Philosophical mapping (object analysis)

| Philosophical term | Idea-entity mapping |
|--------------------|---------------------|
| Substance | Entity identity |
| Properties/qualities | What it is like |
| Relations | How it stands toward others |
| Accidents | Changeable features |
| Essence | What makes it this kind |
| Potentiality | What it can become |
| Actuality | Current expression |
