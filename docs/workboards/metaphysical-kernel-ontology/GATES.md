# Gates

G0 semantic authority: cite v1.1 sections and allocate atomic obligations.
G1 contract lock: version schemas, invariants, compatibility, and exclusions.
G2 persistence: prove migration, provenance, and lifecycle preservation.
G3 runtime: demonstrate the smallest public vertical slice.
G4 conformance: run acceptance and adversarial tests.
G5 release: publish dependency contract, merge evidence, and residual risks.

No task is done without live verification evidence, exact commands, changed paths, and stated residual risk.
