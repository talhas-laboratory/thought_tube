# Gates

G0 semantic authority: cite §7 and dependency assumptions.
G1 contract lock: version support, inheritance, merge, and abstention behavior.
G2 persistence: preserve branch provenance and source reuse.
G3 runtime: demonstrate branch-safe operations.
G4 conformance: pass contradiction, non-explosion, merge, and traversal tests.
G5 release: publish consumer contract, merge evidence, and residual risks.

No task is done without live verification evidence, exact commands, changed paths, and stated residual risk.
