## Scope

Lock the agent interaction pattern as a design contract before runtime work:

1. **Environment frame (once per neighborhood stretch)**  
   A general descriptive prompt / orientation that situates the agent inside a projected neighborhood of the preserved meaning-space, collapsing open semantic probability into that local field for a stretch of work.

2. **Per-turn specification inventory**  
   Each turn receives a budgeted **list** of explicitly mentioned and defined characteristics — entities, qualities, relations, states, constraints, unknowns — not a single isolated packet and not an ocean dump. Implied or merely nearby items stay out by default.

3. **Authority rule**  
   The environment is a governed projection of preserved records and established form. The agent may elaborate inside the frame, but may not mint canon. New structure returns as candidate material for critique/review.

4. **Re-grant rule**  
   Neighborhoods are sticky for focus, but re-openable when purpose, conflict, or readiness changes.
