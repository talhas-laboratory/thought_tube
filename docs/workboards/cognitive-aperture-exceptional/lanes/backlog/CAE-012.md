# CAE-012 — Cross-surface metrics/operator view

**Stage:** D
**Priority:** low
**Depends on:** CAE-006B

## Outcome

Operators can compare aperture quality, empty/abstention reasons, leakage, budgets, and latency without exposing sensitive evidence.

## Acceptance

- metrics derive from receipts/baselines rather than a new truth store;
- privacy-preserving aggregation;
- Bridge/Holodeck and later adapters comparable by revision;
- dashboard has no control-plane mutation path unless separately authorized.
