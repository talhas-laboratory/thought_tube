# Community Pipeline and Reasoning Clustering

**Date:** Jul 2026 design thread  
**Layer:** Network / growth flywheel

---

## Flywheel

```text
Social attention
  → Waitlist mimic-bot (5–10 turns)
  → ReasoningSignature extraction
  → Cluster assignment
  → Product lane per cluster
  → Founder dashboard feedback
  → Connect compatible minds
  → Repeat
```

---

## Core assets

1. **Reasoning model per person** — not just content preferences
2. **Cluster map** — reasoning topologies, not demographics
3. **Product mutation per cluster** — same kernel, different shells

---

## Mimic-reasoning bot

Copies **interrogation style**, not content.

After intake → provisional signature → cluster label → early access.

Example signature (Pilot 003):

```text
stress-tested systems builder:
  ground mechanism → triangulate → demand concretion → escalate abstraction
  → bridge product → formalize → symmetry → inversion → seek canon
```

## People ↔ people matching

Match on **compatible reasoning moves**, not shared topics:

- bridge-builders ↔ formalizers
- inverters ↔ symmetrists (mutual stress-test)

Gentner/SDS insight applied to community: match **relations between people**, not surface attributes.
