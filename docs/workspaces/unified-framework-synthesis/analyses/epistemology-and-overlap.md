# Epistemology and Ontology Overlap

**Date:** Jul 2026 design thread

## Are they competing ontologies?

**No.** Three coordinate systems on one object.

**Are they concurring epistemologies?** **Mostly yes** on first principles; they diverge on what to canonize and how to validate.

---

## Shared epistemological commitments

All three reject naive text-storage:

| Commitment | MTSF | SDS | ThoughtShape |
|------------|------|-----|--------------|
| Meaning is relational | ✓ | ✓ | ✓ |
| Pre-explicit thought is real | ThoughtField | Field | Field |
| Context localizes meaning | Activation context | Observer lens | Frame + lens |
| Provenance mandatory | Assertion store | Evidence spans | StateClaim provenance |
| Ambiguity can remain | Silence invariant | Missing info flagged | Hold |
| Cross-domain ≠ keywords | Stencil index | Movement archetype | Compare by tension |

---

## Divergent epistemic bets

| Question | MTSF | SDS | ThoughtShape |
|----------|------|-----|--------------|
| Primary unit of truth | Shape/stencil | Movement signature | StateClaim topology |
| Latent space real? | No (bridge only) | Metaphor only | Not addressed |
| What validates match? | Stencil + utility eval | 5-layer evaluator + transfer ledger | Lens fidelity to shape |
| Observer role | Secondary | Constitutive | Constitutive |
| Main failure mode | Over-structure | False analogy | Flatten dimensions |

## Conclusion

One underlying reality. Three perspectives:

- **ThoughtShape** — what meaning *is*
- **MTSF** — what the system *remembers*
- **SDS** — what the system *infers about motion*

Merge into one object model with multiple views — not three parallel systems.
