# Shape Intelligence — Normalization

Child of [Shape Intelligence Population](../shape-intelligence-population/README.md). Owns the automatic deterministic `normalize_source` capability: lossless parsing, stable source/segment IDs, offsets, structure, metadata, and deterministic redaction/classification. It is pipeline infrastructure, not an agent-callable tool, and never interprets meaning or identifies Shapes. See [Tool Boundaries](../shape-intelligence-population/derived/TOOL_BOUNDARIES.md).
