# Cognitive Aperture Exceptional

A modular program for safe, efficient disclosure over a large private knowledge world.

The workspace builds the doorway—policy, admission, evidence budgeting, execution-safe projection, receipts, and adapters. It does not own ingestion, canonical Shape formation, embeddings, or source truth.

## Product promise

> Place an agent in the correct knowledge neighborhood with thin orientation, explicit permission, dense evidence, hard budgets, and an inspectable receipt—without loading the ocean or duplicating its truth.

## Reliable-v1 bar

- corpus and Shape dependencies report readiness explicitly;
- Bridge and Holodeck share one disclosure contract;
- unrelated requests fail empty;
- privacy, grant, and budget rules are mechanically enforced;
- execution cannot receive suppressed material;
- Shape candidates preserve status and provenance;
- quality and latency baselines are published;
- every path has feature flags and rollback.
