## Product claim this workspace serves

> Maintain a vast private semantic world, then disclose by state: orient first, grant permission, open high-signal evidence, freeze a receipt.

Foreign intelligence should enter the **correct neighborhood** of the Inner World with almost no distractors, thin orientation, hard budgets, and inspectable proof.

## Non-claims

- Context packets are receipts / boundaries, not the primary steering mind.
- Long-context stuffing is not a substitute for aperture selection.
