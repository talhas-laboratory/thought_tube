# Shape Intelligence — Evidence Assembly

Child of [Shape Intelligence Population](../shape-intelligence-population/README.md). Owns automatic deterministic `build_evidence_packet`: bounded, injection-safe, provenance-complete views assembled before intelligence runs. It is orchestration infrastructure, not an agent-callable tool, and does not decide what a Shape means. See [Tool Boundaries](../shape-intelligence-population/derived/TOOL_BOUNDARIES.md).

Implementation must begin with the [Evidence Remediation Packet](derived/REMEDIATION_PACKET.md) and then its linked central plan.
