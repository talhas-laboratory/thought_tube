# Product

Product coordination folders live here. These are not general research notes; they are durable operating folders for active product systems.

## Active Spines

- [Semantic Operating Layer](semantic-operating-layer/README.md): product spine for the interconnecting systems behind Inner Space's bridge, context, memory, evaluation, and agent coordination layer.

## Folder Standard

Each active product spine should include:

- a root `README.md`
- a systems or module map
- connection/interface rules
- mandatory gates
- decision log
- append-only update log
- subproject packets for independently buildable domains
