# Lens Layer

Status: `seeded`  
Owner: `unassigned`  
First contract: `LensPack`

## Responsibility

Provide bounded world models for domains without bloating the base bridge.

## Scope In

- domain dimensions
- extraction rules
- object schemas
- packet templates
- evaluator labels
- retrieval preferences

## Scope Out

- universal ontology replacement
- surface-specific UI

## Integration

Consumes purpose and topology. Feeds frame compilation, execution packets, and semantic gates.

## First Tasks

- Define minimal `LensPack` manifest.
- Select first lens: product/building work.
- Define lens activation rules and fallback behavior.

## Acceptance Criteria

- Lens packs are optional and bounded.
- Base bridge works without any lens.
- Lens output remains inspectable and correctable.
